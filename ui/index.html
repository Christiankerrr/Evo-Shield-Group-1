2Label and features

Choose which column says whether a row is an attack, then mark the values that mean benign. Everything else counts as an attack.

Numeric columns are min–max scaled to −1…1. Text columns are one-hot encoded, so each distinct value becomes its own input node. Wide text columns such as service add a lot of inputs, which makes training slower.

3Train

Each generation evaluates every network in the population on the sampled rows. The first run also compiles the trainer if the C++ code changed.
